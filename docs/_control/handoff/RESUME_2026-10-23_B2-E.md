## 兜底 hook（仅在重启后 B.2 仍失败且用户批准后安装）
文件 `.claude/hooks/deny_guard.py`：
```python
#!/usr/bin/env python3
# PreToolUse(Bash) 守卫：命中即 exit 2 拦截
import json, re, sys
cmd = json.load(sys.stdin).get("tool_input", {}).get("command", "")
PATS = [
    (r"\bgit\b[^;&|\n]*\bpush\b", "git push"),
    (r"\bgh\b[^;&|\n]*\bpr\s+(merge|create)\b", "gh pr merge/create"),
    (r"(^|[;&|`(\s])pass(\s|$)", "pass"),
]
for pat, name in PATS:
    if re.search(pat, cmd):
        print(f"deny_guard: blocked {name}", file=sys.stderr)
        sys.exit(2)
sys.exit(0)
```
`.claude/settings.json` 顶层增加：
```json
"hooks": {
  "PreToolUse": [
    {"matcher": "Bash",
     "hooks": [{"type": "command",
                "command": "python3 \"$CLAUDE_PROJECT_DIR\"/.claude/hooks/deny_guard.py"}]}
  ]
}
```
安装后重启会话，再重测 B.2。
