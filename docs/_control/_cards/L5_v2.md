D4 B4-tiebreak：AMBIGUOUS 时，按 proposal 顺序取第一个属于 passing 的 structure_id → common_action([h]) → 只有得到 UPDATE_MODEL_AND_REPLAN 才走原授权门（authorize 不变）；gate_reason 记为 "TEXT_TIEBREAK"。遇到 fault ID、未知 ID、空结果、error、超时、ReplayCacheMiss → 回落 strict（PAUSE），gate_reason 记 "TIEBREAK_FALLBACK:<原因>"。LLM 永远不触发锁存。
D5 episode 入口：run_episode 新增 s2_variant: Literal["B3","B4_STRICT","B4_TIEBREAK"]="B3" 和 proposer=None；取默认值时行为与哈希不变。text_context 只进入 B4 请求。
D6 回放：providers 新增 finalize_payload(request_body, settings)，NIM 与 Replay 共用；缓存键 = finalize 后 payload 的 sha256。adapter 不再写 model（由 provider 决定）。
D7 L5-1：actual_x_at_execution / execution_time 移入 s2_diagnostic_trace（按 target_id 关联），evaluator_objects 中不再出现。
D8 L5-2：known_config 导出新增 episode_steps、object_count（同步更新 C1 白名单）；决策点 time 取 presence 行的实际 time；feedback 的 seq 优先从 command_id 解析，command_id 不含 step 时在导出里显式加 step 列；禁止从浮点时间 round 推 seq。l3_equivalence.py 与 load_packets 去掉所有字面常量。
