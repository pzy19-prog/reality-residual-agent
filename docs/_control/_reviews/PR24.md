  2. 同文件，S2 块之后：`if target in holds and s2_action is not Action.PAUSE_AND_REOBSERVE and target not in system2_authorized: finish_reobserve_hold(...)`。`s2_action` 为 None 时 `is not PAUSE` 为真，同样会提前结束。

  - 现有测试 `test_escalated_target_is_reobserved_after_half_second_and_held_from_fast_commands` 没能发现这个问题，推断（INFERENCE）是因为它的场景里升级状态并不连续。
