# RRA-V0-DIAG-01 — dev-seed 诊断

## 范围与方法

- 只使用 `config/dev_seeds.json` 中的 seeds `0–129`，14 个场景，off/on 两种模式；未运行 eval，也未读取 eval artifact。
- 未修改 `src/`、扰动参数或阈值。使用运行时只读拦截记录 `Controller.execute_2d` 的输入/结果；原实现仍负责执行。
- `silent_fail` 定义：在 episode 升级数为 0 时，失败的生成物体数。失败包括未发出抓取命令；发生升级的 episode 不计入 silent_fail。
- 逐条列表中的 `object_id` 是 episode 内 target/object ID。失败分类根据 Controller 的 position/time 判定；拒绝单列。

## 三项诊断结论

- **(A) on 模式静默失败：是。** nominal 24；bias-low 24；drift-low 47；其他场景见表。
- **(B) 低档补偿致损：是。** bias-low 24 个、drift-low 23 个 object 在 off 成功而 on 失败。记录中的最后补偿分别为 residual `0.0800` / time_delta `0.0800`，以及 residual `0.0632` / time_delta `0.0608`；位置补偿均为 0。
- **(C) nominal 约 1.4% 失败：是，dev 上约 1.54%。** off/on 均为 24/1,560 = 1.538%；逐条项全部是时间类未发出抓取。
